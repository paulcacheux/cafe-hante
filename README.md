# Le Café Hanté ☕👻

A small Halloween café game, written in plain HTML/CSS/JS with no build step.

## Run locally
    python3 -m http.server 8000   # then open http://localhost:8000

## Customize
Edit the `CONFIG` block at the top of `game.js` (name, signature, favorite drink, final message).

## Deploy (GitHub Pages)
Push to a GitHub repo, then go to Settings → Pages → "Deploy from a branch" → `main` / root.
